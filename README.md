# 🐦 Flappy Bird — Godot

A simple **Flappy Bird-style 2D game** built with the **Godot Engine**.

The player controls a bird that must fly through gaps between pipes while avoiding collisions.
The project includes gameplay scripts, scenes, assets, UI, a day/night cycle, and a game-over system.

## 🎮 Features

- 🐦 Flappy Bird-style flying gameplay
- 🏗️ Procedural/continuous obstacle gameplay
- 🌙 Day/night cycle
- 💀 Game-over system
- 🖥️ Game UI
- 🎨 Custom game assets
- ⚙️ Built using Godot

## 📁 Project Structure

```text
flappy-bird/
├── assets/              # Images, sprites, audio and other game assets
├── scenes/              # Godot scene files
├── scripts/             # Main gameplay scripts
├── ui/                  # User interface files/assets
├── day_night_cycle.gd   # Day/night cycle logic
├── game_over.gd         # Game-over logic
├── ground.gd            # Ground-related gameplay logic
├── icon.svg             # Project icon
├── project.godot        # Main Godot project configuration
└── .godot/              # Godot-generated editor/cache data (not required in Git)
```

> **Note:** `.gd.uid` files are generated by Godot for script identification. They can be kept with their corresponding `.gd` files.

## 🛠️ Requirements

- [Godot Engine](https://godotengine.org/)
- A desktop operating system supported by Godot

The project was developed as a **2D Godot game**.

## ▶️ How to Run

1. Clone or download this repository.
2. Open **Godot Engine**.
3. Select **Import** / **Scan** and open the project folder.
4. Make sure `project.godot` is present.
5. Open the project.
6. Press **F6** to run the current scene or **F5** to run the main project.

## 🕹️ Controls

| Action | Control |
|---|---|
| Fly / Flap | `Space` |
| Restart after Game Over | Use the on-screen restart option |

> Controls may be changed in the Godot project settings depending on the current implementation.

## 📦 Git / Upload Notes

The `.godot/` folder contains Godot-generated editor/import/cache data and normally **should not be committed or uploaded**.

Recommended project files to keep:

- `assets/`
- `scenes/`
- `scripts/`
- `ui/`
- `project.godot`
- `.gd` scripts
- `.gd.uid` files
- `icon.svg`
